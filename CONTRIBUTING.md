# Contributing to Dynamo Agent Plugins

Thanks for your interest in Dynamo Agent Plugins.

This repository is **not currently accepting external code contributions**. It contains compatibility layers between agent frameworks and [NVIDIA Dynamo](https://github.com/ai-dynamo/dynamo); changes are coordinated tightly with those upstream projects, so we keep the contribution surface closed.

If you would like to:

- **Report a bug** or unexpected behavior — please open a [GitHub issue](https://github.com/ai-dynamo/agent-plugins/issues).
- **Request a feature** or integration improvement — please open a [GitHub issue](https://github.com/ai-dynamo/agent-plugins/issues) describing the use case. We will evaluate whether it belongs here, in the agent framework, or in Dynamo.
- **Discuss broader Dynamo-related changes** — please use the [ai-dynamo/dynamo](https://github.com/ai-dynamo/dynamo) issue tracker or the [CNCF #ai-dynamo Slack channel](https://communityinviter.com/apps/cloud-native/cncf).

If at some point we open this repository to external contributions, this file will be updated with Developer Certificate of Origin (DCO) sign-off and pull-request guidance.
